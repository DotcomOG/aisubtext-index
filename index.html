How It Works

The Methodology

Every score in this index is generated by the same process we use for client audits — no proxies, no estimates.

01
Query Generation

We generate 7 buyer-intent questions per company — the kind a real prospect would ask an AI assistant before making a purchase decision.

02
Multi-Engine Testing

Each question is submitted to ChatGPT, Claude, Gemini, and Perplexity. Responses are captured verbatim and stored for analysis.

03
Accuracy Scoring

Responses are evaluated across four dimensions: category accuracy, explanation quality, context relevance, and feature recognition. Scores run 0–100.
